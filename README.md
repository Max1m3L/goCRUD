# API's:

- ### GET    /spaceships           - список всех кораблей
- ### POST   /spaceships           - создать корабль
- ### GET    /spaceships/{id}      - получить корабль по ID
- ### PUT    /spaceships/{id}      - обновить корабль
- ### DELETE /spaceships/{id}      - удалить корабль
- ### POST   /spaceships/{id}/refuel - заправить корабль
